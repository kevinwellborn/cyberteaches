AP CSP topic 4.1

The Internet

The internet is a network of networks that connects computing devices around the world. Data is broken into small packets that travel separately, possibly by different routes, and are reassembled at the destination. Protocols are agreed-upon rules that make this work: IP addresses devices and routes packets, TCP makes sure all packets arrive in order, and HTTP is used for web pages. The World Wide Web is one system that runs on top of the internet, not the internet itself.

The Internet vocabulary

  • Packet: A small chunk of data sent across a network with addressing information.
  • Protocol: An agreed set of rules for how data is sent and received.
  • IP address: A unique number that identifies a device on the internet.
  • Bandwidth: The maximum amount of data that can be sent in a fixed amount of time.

Skill: Computing Innovations

1. Which of the following best describes how data is sent across the internet?

  1. (A) The whole file travels in one piece along one fixed wire
  2. (B) Data is split into packets that may take different routes and are reassembled at the destination
  3. (C) Data is printed and mailed
  4. (D) Data travels only through satellites
Show answer

(B) Data is split into packets that may take different routes and are reassembled at the destination Packet switching sends data in packets that can take different paths.

Skill: Computing Innovations

2. Which of the following best explains why devices made by different companies can communicate over the internet?

  1. (A) They all use the same brand of hardware
  2. (B) They follow shared, open protocols
  3. (C) They are controlled by one company
  4. (D) They use the same password
Show answer

(B) They follow shared, open protocols Open protocols are agreed rules that any device can follow.

Skill: Computing Innovations

3. What is the role of TCP when packets arrive at their destination?

  1. (A) It makes the packets smaller
  2. (B) It checks that all packets arrived and puts them in the correct order
  3. (C) It encrypts all web pages
  4. (D) It chooses the fastest Wi-Fi network
Show answer

(B) It checks that all packets arrived and puts them in the correct order TCP handles reliable, ordered delivery and requests missing packets.

Skill: Computing Innovations

4. Which of the following correctly describes the relationship between the internet and the World Wide Web?

  1. (A) They are the same thing
  2. (B) The Web is a system of linked pages that runs on the internet
  3. (C) The internet runs on the Web
  4. (D) The Web is the hardware of the internet
Show answer

(B) The Web is a system of linked pages that runs on the internet The internet is the network; the Web is one service that uses it, through HTTP.
