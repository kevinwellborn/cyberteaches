Unit 1: Using Objects and Methods vocabulary

  • Algorithm: A step-by-step process for solving a problem or completing a task. 1.1 Introduction to Algorithms, Programming, and Compilers →
  • Compiler: A program that checks source code for syntax errors and translates it into code the computer can run. 1.1 Introduction to Algorithms, Programming, and Compilers →
  • Syntax error: A mistake in the rules of the language, such as a missing semicolon, found when the code is compiled. 1.1 Introduction to Algorithms, Programming, and Compilers →
  • Exception: An error that happens while a program is running and stops it, such as dividing an int by zero. 1.1 Introduction to Algorithms, Programming, and Compilers →
  • Variable: A named place in memory that stores a value of a specific type. 1.2 Variables and Data Types →
  • Primitive type: A basic type that stores its value directly: int, double, or boolean on the AP exam. 1.2 Variables and Data Types →
  • Reference type: A type, such as String or a class you write, whose variables store the address of an object. 1.2 Variables and Data Types →
  • Declaration: A statement that creates a variable by giving its type and name, such as double price; 1.2 Variables and Data Types →
  • Literal: A value written directly in code, such as 42, 3.14, true, or "hi". 1.3 Expressions and Output →
  • Integer division: Dividing two ints, which keeps only the whole number part of the answer. 1.3 Expressions and Output →
  • Remainder operator (%): Gives the remainder after division; 17 % 5 is 2. 1.3 Expressions and Output →
  • Operator precedence: The order Java evaluates operators: parentheses, then * / %, then + -. 1.3 Expressions and Output →
  • Assignment operator (=): Stores the value on the right side into the variable on the left side. 1.4 Assignment Statements and Input →
  • Initialize: To give a variable its first value. 1.4 Assignment Statements and Input →
  • Scanner: A Java class used to read input, such as numbers and text typed by the user. 1.4 Assignment Statements and Input →
  • Input: Data a program receives while it runs, such as keyboard entry or a file. 1.4 Assignment Statements and Input →
  • Casting: Converting a value to another type, written as (type) value. 1.5 Casting and Range of Variables →
  • Truncation: Cutting off the decimal part of a number without rounding. 1.5 Casting and Range of Variables →
  • Integer overflow: What happens when an int result is too large or small to store; the value wraps around to the other end. 1.5 Casting and Range of Variables →
  • Integer.MAX_VALUE: A constant holding the largest value an int can store. 1.5 Casting and Range of Variables →
  • Compound assignment: An operator like += that combines arithmetic and assignment. 1.6 Compound Assignment Operators →
  • Increment (++): Adds 1 to a variable. 1.6 Compound Assignment Operators →
  • Decrement (--): Subtracts 1 from a variable. 1.6 Compound Assignment Operators →
  • Trace table: A table that tracks the value of each variable as code runs line by line. 1.6 Compound Assignment Operators →
  • API: Documentation that describes how to use a set of classes and their methods. 1.7 Application Program Interface (API) and Libraries →
  • Library: A collection of prewritten classes that programs can use. 1.7 Application Program Interface (API) and Libraries →
  • Package: A group of related classes, such as java.util. 1.7 Application Program Interface (API) and Libraries →
  • Procedural abstraction: Using a method by knowing what it does, without needing to know how it does it. 1.7 Application Program Interface (API) and Libraries →
  • Comment: A note in the code for people to read; the compiler ignores it. 1.8 Documentation with Comments →
  • Javadoc comment: A /** */ comment that documents a class or method and can be turned into web documentation. 1.8 Documentation with Comments →
  • Precondition: A condition that must be true before a method is called for it to work correctly. 1.8 Documentation with Comments →
  • Postcondition: A condition that is guaranteed to be true after a method finishes. 1.8 Documentation with Comments →
  • Method signature: A method name together with the types and order of its parameters. 1.9 Method Signatures →
  • Parameter: A variable in a method header that receives a value when the method is called. 1.9 Method Signatures →
  • Argument: The actual value passed into a method when it is called. 1.9 Method Signatures →
  • Overloading: Having two or more methods with the same name but different parameter lists. 1.9 Method Signatures →
  • Class method: A static method that is called on the class, not on an object. 1.10 Calling Class Methods →
  • static: A keyword meaning a method or variable belongs to the class as a whole. 1.10 Calling Class Methods →
  • Dot operator: The . used to call a method or reach a variable of a class or object. 1.10 Calling Class Methods →
  • Return value: The value a non-void method sends back to the code that called it. 1.10 Calling Class Methods →
  • Math.abs: Returns the absolute value of an int or double. 1.11 Math Class →
  • Math.pow: Returns the first argument raised to the power of the second, as a double. 1.11 Math Class →
  • Math.sqrt: Returns the square root of a value as a double. 1.11 Math Class →
  • Math.random: Returns a random double that is at least 0.0 and less than 1.0. 1.11 Math Class →
  • Class: A blueprint that defines the attributes and behaviors of a type of object. 1.12 Objects: Instances of Classes →
  • Object: A specific instance of a class, with its own values for the attributes. 1.12 Objects: Instances of Classes →
  • Attribute: Data that an object holds, stored in instance variables. 1.12 Objects: Instances of Classes →
  • Behavior: An action an object can do, written as a method. 1.12 Objects: Instances of Classes →
  • Instantiation: Creating a new object from a class using new. 1.13 Object Creation and Storage (Instantiation) →
  • Constructor: Special code that runs when an object is created and sets its starting values. 1.13 Object Creation and Storage (Instantiation) →
  • Reference: A value that tells where an object is stored in memory. 1.13 Object Creation and Storage (Instantiation) →
  • null: A special value meaning a reference variable does not point to any object. 1.13 Object Creation and Storage (Instantiation) →
  • Instance method: A method that is called on a specific object and uses that object's data. 1.14 Calling Instance Methods →
  • NullPointerException: An exception thrown when code calls a method on a null reference. 1.14 Calling Instance Methods →
  • Accessor method: A method that returns information about an object without changing it, often named getSomething. 1.14 Calling Instance Methods →
  • Mutator method: A method that changes an object's data, often named setSomething. 1.14 Calling Instance Methods →
  • String: An object that holds a sequence of characters, such as "hello". 1.15 String Manipulation →
  • Immutable: Cannot be changed after it is created; String methods return new Strings. 1.15 String Manipulation →
  • Index: The position of a character in a String, starting at 0. 1.15 String Manipulation →
  • substring: A method that returns part of a String, from a start index up to but not including an end index. 1.15 String Manipulation →

Unit 2: Selection and Iteration vocabulary

  • Sequencing: Running steps one after another in order. 2.1 Algorithms with Selection and Repetition →
  • Selection: Choosing which code to run based on whether a condition is true. 2.1 Algorithms with Selection and Repetition →
  • Iteration: Repeating a set of steps, usually with a loop. 2.1 Algorithms with Selection and Repetition →
  • Flowchart: A diagram that shows the steps and decisions of an algorithm. 2.1 Algorithms with Selection and Repetition →
  • Boolean expression: An expression that evaluates to true or false. 2.2 Boolean Expressions →
  • Relational operator: An operator that compares two values: ==, !=, <, >, <=, >=. 2.2 Boolean Expressions →
  • boolean: A primitive type with only two values, true and false. 2.2 Boolean Expressions →
  • Condition: A Boolean expression that controls whether code runs. 2.2 Boolean Expressions →
  • if statement: Code that runs a block only when a condition is true. 2.3 if Statements →
  • else: The part of an if statement that runs when the condition is false. 2.3 if Statements →
  • Branch: One of the possible paths through a selection statement. 2.3 if Statements →
  • Block: A group of statements inside curly braces { }. 2.3 if Statements →
  • Nested if: An if statement placed inside another if or else block. 2.4 Nested if Statements →
  • else if: A branch that checks a new condition only when all earlier conditions were false. 2.4 Nested if Statements →
  • Multiway selection: An if-else if-else chain where exactly one of several branches runs. 2.4 Nested if Statements →
  • Dangling else: An else that pairs with the nearest unmatched if, which can surprise programmers when braces are left out. 2.4 Nested if Statements →
  • && (and): True only when both conditions are true. 2.5 Compound Boolean Expressions →
  • || (or): True when at least one condition is true. 2.5 Compound Boolean Expressions →
  • ! (not): Reverses a Boolean value. 2.5 Compound Boolean Expressions →
  • Short-circuit evaluation: Stopping a && or || expression as soon as the answer is known. 2.5 Compound Boolean Expressions →
  • Equivalent expressions: Boolean expressions that give the same value for all inputs. 2.6 Comparing Boolean Expressions →
  • Truth table: A table showing the result of a Boolean expression for every combination of inputs. 2.6 Comparing Boolean Expressions →
  • De Morgan's laws: Rules for negating && and ||: !(a && b) == !a || !b and !(a || b) == !a && !b. 2.6 Comparing Boolean Expressions →
  • Alias: Two reference variables that point to the same object. 2.6 Comparing Boolean Expressions →
  • while loop: A loop that repeats while its condition is true. 2.7 while Loops →
  • Loop body: The statements that are repeated by a loop. 2.7 while Loops →
  • Infinite loop: A loop whose condition never becomes false, so it never ends. 2.7 while Loops →
  • Sentinel value: A special input value that tells a loop to stop. 2.7 while Loops →
  • for loop: A loop with initialization, condition, and update written in one header. 2.8 for Loops →
  • Loop control variable: The variable, often i, that counts or controls the passes of a loop. 2.8 for Loops →
  • Off-by-one error: A bug where a loop runs one time too many or too few. 2.8 for Loops →
  • Iteration count: The number of times a loop body runs. 2.8 for Loops →
  • Accumulator: A variable that builds up a total as a loop runs. 2.9 Implementing Selection and Iteration Algorithms →
  • Counter: A variable that counts how many times something happens. 2.9 Implementing Selection and Iteration Algorithms →
  • Running maximum: A variable that holds the largest value seen so far. 2.9 Implementing Selection and Iteration Algorithms →
  • Digit extraction: Using % 10 to get the last digit of a number and / 10 to remove it. 2.9 Implementing Selection and Iteration Algorithms →
  • Traverse: To visit every element, such as every character in a String, in order. 2.10 Implementing String Algorithms →
  • Concatenation: Joining Strings together with +. 2.10 Implementing String Algorithms →
  • Reverse: To build a new String with the characters in the opposite order. 2.10 Implementing String Algorithms →
  • Pattern: A smaller String being searched for inside a larger one. 2.10 Implementing String Algorithms →
  • Nested loop: A loop placed inside the body of another loop. 2.11 Nested Iteration →
  • Outer loop: The loop that contains another loop. 2.11 Nested Iteration →
  • Inner loop: The loop inside; it runs completely for each pass of the outer loop. 2.11 Nested Iteration →
  • Total iterations: For simple nested loops, the outer count times the inner count. 2.11 Nested Iteration →
  • Statement execution count: The number of times a particular statement runs. 2.12 Informal Run-Time Analysis →
  • Run time: How long an algorithm takes, often measured by counting steps. 2.12 Informal Run-Time Analysis →
  • Efficiency: How well an algorithm uses time and memory. 2.12 Informal Run-Time Analysis →
  • Input size: The amount of data, often called n, that an algorithm processes. 2.12 Informal Run-Time Analysis →

Unit 3: Class Creation vocabulary

  • Abstraction: Hiding details to manage complexity and focus on the big idea. 3.1 Abstraction and Program Design →
  • Data abstraction: Grouping related data into one type and giving it a name. 3.1 Abstraction and Program Design →
  • Class diagram: A diagram that shows a class name, its variables, and its methods. 3.1 Abstraction and Program Design →
  • Decomposition: Breaking a problem into smaller parts, like classes and methods. 3.1 Abstraction and Program Design →
  • System reliability: How well a program works correctly under all expected conditions. 3.2 Impact of Program Design →
  • Intellectual property: Creations such as code that belong to their creator and are protected by law. 3.2 Impact of Program Design →
  • License: Permission that states how others may use, change, or share code. 3.2 Impact of Program Design →
  • Bias: Unfair results that favor or harm certain groups, which can be built into software by accident. 3.2 Impact of Program Design →
  • Instance variable: A variable declared in a class that each object gets its own copy of. 3.3 Anatomy of a Class →
  • private: An access modifier that allows use only inside the class. 3.3 Anatomy of a Class →
  • public: An access modifier that allows use from any class. 3.3 Anatomy of a Class →
  • Encapsulation: Keeping an object's data private and controlling access through methods. 3.3 Anatomy of a Class →
  • Default constructor: A constructor with no parameters; Java supplies one if you write none. 3.4 Constructors →
  • Default values: Starting values Java gives instance variables: 0, 0.0, false, or null. 3.4 Constructors →
  • Overloaded constructors: Several constructors in one class with different parameter lists. 3.4 Constructors →
  • Method header: The first line of a method: access, return type, name, and parameters. 3.5 Methods: How to Write Them →
  • return statement: Sends a value back to the caller and ends the method. 3.5 Methods: How to Write Them →
  • void: A return type meaning the method does not return a value. 3.5 Methods: How to Write Them →
  • toString: A method that returns a String describing an object. 3.5 Methods: How to Write Them →
  • Pass by value: Giving a method a copy of the argument's value. 3.6 Methods: Passing and Returning References of an Object →
  • Formal parameter: The variable in the method header that receives the argument. 3.6 Methods: Passing and Returning References of an Object →
  • Actual parameter: Another name for the argument passed in the method call. 3.6 Methods: Passing and Returning References of an Object →
  • Mutable object: An object whose data can be changed after it is created. 3.6 Methods: Passing and Returning References of an Object →
  • Class variable: A static variable shared by all objects of a class. 3.7 Class Variables and Methods →
  • Static method: A method that belongs to the class and has no this object. 3.7 Class Variables and Methods →
  • final: A keyword that makes a variable unchangeable after it is set. 3.7 Class Variables and Methods →
  • Constant: A value that does not change, often declared public static final. 3.7 Class Variables and Methods →
  • Scope: The region of code where a variable can be used. 3.8 Scope and Access →
  • Local variable: A variable declared inside a method or block; it disappears when the block ends. 3.8 Scope and Access →
  • Shadowing: When a local variable or parameter hides an instance variable with the same name. 3.8 Scope and Access →
  • Access modifier: A keyword such as public or private that controls who can use a member. 3.8 Scope and Access →
  • this: A reference to the object whose method or constructor is running. 3.9 this Keyword →
  • Current object: The object on which an instance method was called. 3.9 this Keyword →
  • this.variable: Refers to the instance variable, even when a parameter has the same name. 3.9 this Keyword →
  • Implicit parameter: The object a method is called on, reached with this. 3.9 this Keyword →

Unit 4: Data Collections vocabulary

  • Personal data: Information that can identify or describe a specific person. 4.1 Ethical and Social Issues Around Data Collection →
  • Privacy: A person's right to control information about themselves. 4.1 Ethical and Social Issues Around Data Collection →
  • Data bias: Unfairness caused by data that leaves out or misrepresents some groups. 4.1 Ethical and Social Issues Around Data Collection →
  • Informed consent: Agreement to share data after being told how it will be used. 4.1 Ethical and Social Issues Around Data Collection →
  • Data set: A collection of related data, often arranged in rows and columns. 4.2 Introduction to Using Data Sets →
  • Record: One row of a data set, describing one item. 4.2 Introduction to Using Data Sets →
  • Data cleaning: Fixing or removing incorrect, missing, or inconsistent data. 4.2 Introduction to Using Data Sets →
  • Collection: An object that groups many values together, such as an array or ArrayList. 4.2 Introduction to Using Data Sets →
  • Array: A fixed-size collection of elements of the same type. 4.3 Array Creation and Access →
  • Element: One value stored in an array. 4.3 Array Creation and Access →
  • length: The number of elements in an array, written arr.length. 4.3 Array Creation and Access →
  • ArrayIndexOutOfBoundsException: An exception thrown when an index is less than 0 or not less than the length. 4.3 Array Creation and Access →
  • Traversal: Visiting each element of a collection. 4.4 Array Traversals →
  • Enhanced for loop: A loop of the form for (type x : collection) that visits every element. 4.4 Array Traversals →
  • Loop variable copy: In an enhanced for loop, the variable holds a copy of each element, so changing it does not change the array. 4.4 Array Traversals →
  • Bounds: The valid index range, 0 to length - 1. 4.4 Array Traversals →
  • Minimum / maximum: The smallest or largest value in a collection. 4.5 Implementing Array Algorithms →
  • Shift: Moving every element one position left or right. 4.5 Implementing Array Algorithms →
  • Rotate: Shifting elements so the one that falls off one end moves to the other end. 4.5 Implementing Array Algorithms →
  • Adjacent elements: Neighbors in an array, such as arr[i] and arr[i + 1]. 4.5 Implementing Array Algorithms →
  • Text file: A file that stores data as readable characters. 4.6 Using Text Files →
  • File: A Java class that represents a file on the computer. 4.6 Using Text Files →
  • hasNext: A Scanner method that returns true if there is more input to read. 4.6 Using Text Files →
  • split: A String method that breaks a String into an array of parts at a separator. 4.6 Using Text Files →
  • Wrapper class: A class, such as Integer or Double, that stores a primitive value as an object. 4.7 Wrapper Classes →
  • Autoboxing: Automatic conversion of a primitive to its wrapper object. 4.7 Wrapper Classes →
  • Unboxing: Automatic conversion of a wrapper object back to a primitive. 4.7 Wrapper Classes →
  • Integer.parseInt: A method that converts a String of digits into an int. 4.7 Wrapper Classes →
  • ArrayList: A resizable list of objects from java.util. 4.8 ArrayList Methods →
  • size(): Returns the number of elements in an ArrayList. 4.8 ArrayList Methods →
  • Generic type: The type in angle brackets, like <String>, that an ArrayList holds. 4.8 ArrayList Methods →
  • remove(index): Removes and returns the element at an index, shifting later elements left. 4.8 ArrayList Methods →
  • Backward traversal: Looping from the last index down to 0, which makes removing safe. 4.9 ArrayList Traversals →
  • ConcurrentModificationException: Thrown when a list is changed in size during an enhanced for loop. 4.9 ArrayList Traversals →
  • IndexOutOfBoundsException: Thrown when an ArrayList index is out of range. 4.9 ArrayList Traversals →
  • get(index): Returns the element at a position in an ArrayList. 4.9 ArrayList Traversals →
  • Filter: Building a collection of only the items that meet a condition. 4.10 Implementing ArrayList Algorithms →
  • Sorted insertion: Adding an item at the position that keeps a list in order. 4.10 Implementing ArrayList Algorithms →
  • Remove all: Removing every element that meets a condition. 4.10 Implementing ArrayList Algorithms →
  • Parallel lists: Two lists where items at the same index are related. 4.10 Implementing ArrayList Algorithms →
  • 2D array: An array of arrays that stores values in rows and columns. 4.11 2D Array Creation and Access →
  • Row-major order: Visiting a 2D array one full row at a time. 4.11 2D Array Creation and Access →
  • grid.length: The number of rows in a 2D array. 4.11 2D Array Creation and Access →
  • grid[0].length: The number of columns in a rectangular 2D array. 4.11 2D Array Creation and Access →
  • Row-major traversal: Outer loop over rows, inner loop over columns. 4.12 2D Array Traversals →
  • Column-major traversal: Outer loop over columns, inner loop over rows. 4.12 2D Array Traversals →
  • Nested enhanced for: for (int[] row : grid) for (int v : row), visiting every value. 4.12 2D Array Traversals →
  • Cell: One element of a 2D array, at a row and column. 4.12 2D Array Traversals →
  • Row sum: The total of every value in one row. 4.13 Implementing 2D Array Algorithms →
  • Column sum: The total of every value in one column. 4.13 Implementing 2D Array Algorithms →
  • Neighbor: A cell next to another cell in a grid. 4.13 Implementing 2D Array Algorithms →
  • Bounds check: A test that an index is valid before using it. 4.13 Implementing 2D Array Algorithms →
  • Linear search: Checking elements one at a time from the start until the target is found. 4.14 Searching Algorithms →
  • Binary search: Searching sorted data by repeatedly checking the middle and discarding half. 4.14 Searching Algorithms →
  • Target: The value a search is looking for. 4.14 Searching Algorithms →
  • Sorted: Arranged in order, such as smallest to largest. 4.14 Searching Algorithms →
  • Selection sort: Repeatedly selecting the smallest remaining element and swapping it into place. 4.15 Sorting Algorithms →
  • Insertion sort: Inserting each element into its correct place in the sorted part of the list. 4.15 Sorting Algorithms →
  • Swap: Exchanging two elements, using a temporary variable. 4.15 Sorting Algorithms →
  • Pass: One run of the outer loop of a sorting algorithm. 4.15 Sorting Algorithms →
  • Recursive method: A method that calls itself. 4.16 Recursion →
  • Base case: The condition where a recursive method stops calling itself. 4.16 Recursion →
  • Recursive call: A call to the method from inside itself on a smaller problem. 4.16 Recursion →
  • Call stack: The list of method calls waiting to finish, newest on top. 4.16 Recursion →
  • Recursive binary search: Binary search that calls itself on half of the range. 4.17 Recursive Searching and Sorting →
  • Merge sort: A recursive sort that splits, sorts each half, and merges them. 4.17 Recursive Searching and Sorting →
  • Merge: Combining two sorted lists into one sorted list. 4.17 Recursive Searching and Sorting →
  • Divide and conquer: Solving a problem by splitting it into smaller problems of the same kind. 4.17 Recursive Searching and Sorting →
