Implementing ArrayList Algorithms

The array algorithms also work on ArrayLists, using size() and get instead of length and brackets. ArrayLists make some jobs easier, such as building a new list of the items that pass a test, inserting items in sorted order, or removing every item that fails a test. When an algorithm removes items, plan carefully so no element is skipped. Choosing between an array and an ArrayList depends on whether the number of items will change.

Implementing ArrayList Algorithms vocabulary

  • Filter: Building a collection of only the items that meet a condition.
  • Sorted insertion: Adding an item at the position that keeps a list in order.
  • Remove all: Removing every element that meets a condition.
  • Parallel lists: Two lists where items at the same index are related.

ArrayList<Integer> src = new ArrayList<Integer>();
// src contains [3, 8, 5, 12, 6]
ArrayList<Integer> out = new ArrayList<Integer>();
for (int n : src) {
  if (n % 2 == 0) out.add(n);
}
System.out.println(out);

1. What is printed?

  1. (A) [3, 5]
  2. (B) [8, 12, 6]
  3. (C) [3, 8, 5, 12, 6]
  4. (D) [8, 6]
Show answer

(B) [8, 12, 6] The loop filters the even numbers into a new list.

// sorted contains [2, 5, 9]
int val = 6;
int i = 0;
while (i < sorted.size() && sorted.get(i) < val) i++;
sorted.add(i, val);

2. What are the contents of sorted after this code runs?

  1. (A) [2, 5, 9, 6]
  2. (B) [2, 5, 6, 9]
  3. (C) [6, 2, 5, 9]
  4. (D) [2, 6, 5, 9]
Show answer

(B) [2, 5, 6, 9] i stops at 2, the first value not less than 6, and 6 is inserted there to keep the list sorted.

3. When is an ArrayList a better choice than an array?

  1. (A) When the number of items is fixed and known
  2. (B) When items need to be added and removed as the program runs
  3. (C) When storing ints only
  4. (D) Never
Show answer

(B) When items need to be added and removed as the program runs ArrayLists resize automatically.

// names contains ["Al", "Bea", "Cy"]
String longest = names.get(0);
for (String s : names) {
  if (s.length() > longest.length()) longest = s;
}
System.out.println(longest);

4. What is printed?

  1. (A) Al
  2. (B) Bea
  3. (C) Cy
  4. (D) AlBeaCy
Show answer

(B) Bea Bea, with 3 letters, is the longest.
