Expressions and Output

System.out.println prints a value and moves to a new line, while System.out.print stays on the same line. Arithmetic expressions use +, -, *, / and the remainder operator %. When both operands are ints, / does integer division and drops the decimal part, so 7 / 2 is 3, and 7 % 2 is 1. If either operand is a double, the result is a double, so 7.0 / 2 is 3.5. Java follows order of operations: *, / and % happen before + and -, and parentheses come first. A String literal is text in double quotes, and + joins Strings together.

Expressions and Output vocabulary

  • Literal: A value written directly in code, such as 42, 3.14, true, or "hi".
  • Integer division: Dividing two ints, which keeps only the whole number part of the answer.
  • Remainder operator (%): Gives the remainder after division; 17 % 5 is 2.
  • Operator precedence: The order Java evaluates operators: parentheses, then * / %, then + -.

  4. (D) 3.4 then 0.4

(B) 3 then 2 17 / 5 is integer division, which gives 3. The remainder 17 % 5 is 2.

2. What is the value of the expression 2 + 3 * 4 - 6 / 2 ?

  1. (A) 11
  2. (B) 7
  3. (C) 17
  4. (D) 14
Show answer

(A) 11 Multiply and divide first: 3 * 4 = 12 and 6 / 2 = 3. Then 2 + 12 - 3 = 11.
