AP Computer Science A Practice Exam 2

A full-length practice exam in the same format as the AP Computer Science A exam. Every question is original and written for CyberTeaches.

SectionQuestionsTimeWeightWhat it looks like
I: Multiple choice4290 minutes55%Four answer choices each. Most questions ask you to trace Java code: what it prints, what a method returns, or which change makes it work.

Before you start

  • Open the Reference button during the exam to see the Java quick reference. You can also view or print it now.
  • Have scratch paper ready for tracing code. Nothing on this page compiles or runs your code, just like on exam day.
  • Your answers are saved in this browser as you go, so you can close the tab and come back later on the same device.
  • Each section has its own timer. When time runs out, the section is submitted automatically.
  • After Section II, you score your own code with the scoring points and sample solutions, and get an estimated AP score.
Prefer paper? Print the exam booklet (answer sheet, Java quick reference, all 42 questions, and the free-response section). Teachers can add the answer key and scoring guidelines at the end.
