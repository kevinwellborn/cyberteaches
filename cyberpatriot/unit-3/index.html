Windows Hardening, Part 1: Users, Passwords, and Updates

User accounts and password policy are the most reliable points in every Windows round. Learn the Windows admin tools, audit users and groups against a README, set password and lockout policy, and keep Windows Update working.

Time: 4 lessons (50 min) and 2 practice sessions (90 min)Platform: Windows 10/11
Goals

By the end of this unit, students can

  1. Find and use the main Windows admin tools: Settings, Computer Management, Command Prompt, and PowerShell as administrator.
  2. Audit user accounts and groups against a README, and fix unauthorized users and administrators.
  3. Set a secure password policy and account lockout policy.
  4. Check that Windows Update is turned on and working.
Signature lab

Lab 3: Secure User Accounts and Local Security Policy

On a Windows 10/11 Pro or Enterprise VM, students answer the forensics question, fix users and groups against the README, set the password and lockout policy, and check Windows Update. The last run is timed at 50 minutes.

CSTA 3A-NI-06, 3B-NI-04 · NICE: Systems Administration, Cyber Defense Infrastructure Support

Hardening checklist

Add these to your checklist

At the end of the unit, every student adds these lines. Always check the README first: it decides what is required.

CheckHow
Delete users not in the README; remove extra adminsnet user, net localgroup Administrators
Check custom groups match the READMEnet localgroup, then net localgroup NAME
No "password never expires" on usersSet-LocalUser -Name NAME -PasswordNeverExpires $false
Password policy: length 10+, max age 90, min age 1, history 5+, complexity onsecpol.msc, Account Policies, Password Policy
Lockout policy: threshold 5 to 10, duration 30, reset 30secpol.msc, Account Lockout Policy
