Unit 8 of 10 · 3 weeks

Windows Server and Active Directory

Server images usually run Active Directory, so students work at the domain level. Learn Server Manager, audit domain users and privileged groups, set the domain password policy with Group Policy, and secure DNS, SMB, and server roles.

Time: 6 lessons (50 min) and 3 practice sessions (90 min)Platform: Windows Server 2022
Goals

By the end of this unit, students can

  1. Explain what a server, a domain, and a domain controller are, and use Server Manager.
  2. Use Active Directory Users and Computers and PowerShell to audit domain users, groups, and OUs.
  3. Find and fix dangerous account settings and members of privileged groups.
  4. Set the domain password and lockout policy with Group Policy or PowerShell.
  5. Secure server roles: DNS zone transfers, SMBv1, the firewall, and unneeded features.
Signature lab

Lab 8: Full Windows Server Practice Image

On a Windows Server 2022 domain controller, students answer the forensics question, audit domain users and privileged groups, clear risky account flags, set the domain password and lockout policy, lock down DNS zone transfers, remove SMBv1, and check the firewall. The last run is timed at 55 minutes.

CSTA 3B-NI-03, 3B-NI-04 · NICE: Systems Administration, Network Operations

Hardening checklist

Add these to your checklist

At the end of the unit, every student adds these lines. Always check the README first: it decides what is required.

CheckHow
Audit domain users against the READMEGet-ADUser -Filter * | Select Name,Enabled
Privileged groups contain only README adminsGet-ADGroupMember "Domain Admins" (also Enterprise, Schema, Administrators)
No risky account flagsGet-ADUser -Filter * -Properties PasswordNotRequired,DoesNotRequirePreAuth,PasswordNeverExpires
Domain password and lockout policySet-ADDefaultDomainPasswordPolicy, or Default Domain Policy in gpmc.msc
DNS zone transfers off or to listed servers onlyDNS Manager, zone Properties, Zone Transfers
Remove SMBv1Uninstall-WindowsFeature FS-SMB1
Never remove AD DS or DNS on a domain controllerRead the README
