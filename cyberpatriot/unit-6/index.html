CyberPatriot / Unit 6
Unit 6 of 10 · 2 weeks

Linux Hardening

Apply the same audit method from Windows to Ubuntu: users and sudo, hidden root accounts, password aging, the ufw firewall, SSH, services, prohibited software, file permissions, and updates.

Time: 4 lessons (50 min) and 2 practice sessions (90 min)Platform: Ubuntu
Goals

By the end of this unit, students can

  1. Audit Linux users, sudo rights, and hidden root (UID 0) accounts against a README.
  2. Set password aging and minimum length rules.
  3. Turn on the ufw firewall and secure the SSH server.
  4. Remove unneeded services and prohibited software, fix risky file permissions, and install updates.
Signature lab

Lab 6: Full Linux Practice Image

A fresh Ubuntu image with planted problems: forensics question, users and sudo, a hidden UID 0 account, password policy, ufw, SSH settings, unneeded services, prohibited tools, /etc/shadow permissions, and updates. The last run is timed at 55 minutes.

CSTA 3A-NI-06, 3B-NI-04 · NICE: Systems Administration, Cyber Defense Infrastructure Support

Hardening checklist

Add these to your checklist

At the end of the unit, every student adds these lines. Always check the README first: it decides what is required.

CheckHow
Delete unauthorized users; remove extra sudo memberssudo deluser NAME, sudo gpasswd -d NAME sudo
No UID 0 accounts except rootawk -F: '$3==0' /etc/passwd
Strong passwords for all userssudo passwd NAME
Password aging 90/1/7 and minlen 10/etc/login.defs, chage, /etc/security/pwquality.conf
Firewall onsudo ufw enable
SSH root login off (if SSH is required)PermitRootLogin no in /etc/ssh/sshd_config, then restart ssh
Purge unneeded services and prohibited toolssudo apt purge NAME
/etc/shadow is 640sudo chmod 640 /etc/shadow
Install updatessudo apt update && sudo apt upgrade -y
