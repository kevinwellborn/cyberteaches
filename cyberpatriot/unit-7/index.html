Unit 7 of 10 · 3 weeks

Networking and Cisco Basics

Most rounds include a Cisco networking part. Learn how switches and routers move data, IPv4 addressing, the OSI model and common ports, then configure and secure a small network in Cisco Packet Tracer.

Time: 6 lessons (50 min) and 3 practice sessions (90 min)Platform: Cisco Packet Tracer
Goals

By the end of this unit, students can

  1. Explain what switches and routers do, and how devices find each other on a network.
  2. Read and assign IPv4 addresses, subnet masks, and default gateways, and test with ping.
  3. Name the layers of the OSI model and common ports (21, 22, 23, 53, 80, 443, 3389).
  4. Use Cisco IOS modes in Packet Tracer to configure a router and switch.
  5. Secure Cisco devices: passwords, encryption, SSH instead of Telnet, banners, and unused ports.
Signature lab

Lab 7: Configure and Secure a Small Network

In Packet Tracer, students place a router, a switch, and two PCs, cable them, set IP addresses, and test with ping. Then they secure both devices: hostnames, enable secret, line passwords, encryption, a banner, SSH, and shut unused ports. It ends with a 45-minute build from a blank file.

CSTA 3A-NI-04, 3A-NI-05, 3B-NI-03 · NICE: Network Operations
