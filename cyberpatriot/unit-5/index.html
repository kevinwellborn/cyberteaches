Unit 5 of 10 · 2 weeks

Linux Fundamentals

Many students have never used a terminal. Learn to move around the Linux file system, work with files, read and change permissions, use sudo responsibly, and manage packages and services on Ubuntu.

Time: 4 lessons (50 min) and 2 practice sessions (90 min)Platform: Ubuntu or Linux Mint
Goals

By the end of this unit, students can

  1. Move around the Linux file system with the terminal and explain what lives in /etc, /home, /var, and /opt.
  2. Create, read, copy, move, search, and delete files from the terminal.
  3. Read and change file permissions, and use sudo responsibly.
  4. Install and remove software with apt, and check services and listening ports.
Signature lab

Lab 5: Command-Line Scavenger Hunt

Ten terminal challenges on an Ubuntu VM. Each item leads to a flag or an answer: hidden files, searching with find and grep, reading permissions, users and sudo, packages, and listening ports.

CSTA 3A-CS-03, 3B-NI-04 · NICE: Systems Administration
