Unit 2 of 10 · 1 week

Computer and Security Foundations

Learn the vocabulary every later unit uses: hardware, operating systems, users, permissions, least privilege, and common threats. Then build the virtual machine you will practice on all year.

Time: 2 lessons (50 min) and 1 practice session (90 min)Platform: Windows or Ubuntu
Goals

By the end of this unit, students can

  1. Name the main parts of a computer and explain what an operating system does.
  2. Explain user accounts, administrator rights, and file permissions, and why least privilege matters.
  3. Describe common threats: malware, phishing, weak passwords, and unpatched software.
  4. Create, start, snapshot, and restore a virtual machine in VirtualBox or VMware.
Signature lab

Lab 2: Build Your Own Virtual Machine

Each student or pair creates a VM, installs Windows or Ubuntu, takes a snapshot, breaks something on purpose, and restores the snapshot. If installs are slow, import a ready-made .ova and focus on snapshots.
