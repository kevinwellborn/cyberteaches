AP Cybersecurity Practice Exam 1

A full-length practice exam in the same format as the AP Cybersecurity exam. Every question, scenario, log, and policy is original and written for CyberTeaches.

SectionQuestionsTimeWhat it looks like
I: Multiple choice (70%)6080 minutesSingle questions and sets of 2 to 4 questions that share one source: a phishing email, a badge reader log, a risk table, firewall rules, a firewall log, an authentication log, an application log, file permissions, and a file integrity report.
II: Free response (30%)1 question (5 parts, 11 points)50 minutesDevice Security Analysis. Five sources about one server (a device policy, firewall rules, two logs, and a file list). You explain the policy, find the attack in the logs, fix file permissions and firewall rules, and recommend a way to harden the device.

Coverage: Unit 1: 7 questions · Unit 2: 11 · Unit 3: 14 · Unit 4: 13 · Unit 5: 15, in proportion to the class time for each unit. The questions practice the exam's skills: analyze risk, mitigate risk, and detect attacks. Every question links to the course topic to review.

Before you start

  • Have scratch paper ready. Read every source carefully: most answers depend on one detail in a log line, a rule, or a permission string.
  • Your answers are saved in this browser as you go, so you can close the tab and resume later on the same device.
  • Each section has its own timer. When time runs out, the section is submitted automatically.
  • After Section II, you score your own free response with the scoring guidelines and a sample response.
Prefer paper? Print the exam booklet (answer sheet, all 60 questions, and the free-response section). Teachers can add the answer key and scoring guidelines at the end.
