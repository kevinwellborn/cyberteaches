AP Cybersecurity topic 5.5

Protecting Applications

Secure applications validate input, use parameterized queries, encode output, keep libraries updated, and store secrets safely. Security is built in from the start (secure by design), tested with code review and scanning, and backed up so data can be restored after an attack.

Protecting Applications vocabulary

  • Parameterized query: A database query that treats user input strictly as data, blocking SQL injection.
  • Output encoding: Converting special characters so input displays as text instead of running as code.
  • Patch management: Tracking and applying software updates.
  • Backup: A copy of data kept separately so it can be restored.
