Protecting Networks: Segmentation

Segmentation splits a network into zones so an attacker who gets into one part cannot easily reach the rest. Schools might separate student devices, staff devices, guest Wi-Fi, and servers using VLANs and subnets. A DMZ holds public-facing servers away from the internal network.

Protecting Networks: Segmentation vocabulary

  • Segmentation: Dividing a network into separate zones.
  • VLAN: A virtual LAN that groups devices logically, regardless of physical location.
  • DMZ: A buffer zone for public-facing servers.
  • Lateral movement: An attacker moving from one compromised system to others.

Skill: Mitigate Risk

1. A hospital wants to make sure infected guest devices cannot reach patient record servers. Which of the following is the best solution?

  1. (A) Put guest Wi-Fi and patient record servers on separate network segments (VLANs)
  2. (B) Give guests a longer Wi-Fi password
  3. (C) Turn off the patient record servers at night
  4. (D) Put all devices on one large network
Show answer

(A) Put guest Wi-Fi and patient record servers on separate network segments (VLANs) Segmentation keeps untrusted devices away from sensitive systems.

Skill: Analyze Risk

2. Which of the following best explains how network segmentation limits damage after a device is compromised?

  1. (A) It encrypts every file on the device
  2. (B) It restricts the adversary's ability to move laterally to other parts of the network
  3. (C) It removes malware automatically
  4. (D) It speeds up the internet connection
Show answer

(B) It restricts the adversary's ability to move laterally to other parts of the network Walls between segments slow or stop lateral movement.

Skill: Mitigate Risk

3. A company hosts a public website and an internal HR database. Where should the web server be placed?

  1. (A) On the same segment as the HR database
  2. (B) In a screened subnet (DMZ) separated from the internal network
  3. (C) On an employee's laptop
  4. (D) Outside any firewall with no protection
Show answer

(B) In a screened subnet (DMZ) separated from the internal network A DMZ lets the public reach the web server without giving them a path into the internal network.
