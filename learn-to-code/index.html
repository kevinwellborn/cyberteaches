What you will learn

The big ideas of programming, one level at a time

  • Sequences: computers follow your commands in order.
  • Loops: repeat, repeat until and Python for loops do the boring parts for you.
  • Conditionals: if / else lets your program make decisions.
  • Variables: store a number and change it as your program runs.
  • Debugging: find the bug, fix it, try again. Fewer blocks earns more stars.

Questions

Frequently asked questions

Is it free?

Yes. Every game and course on CyberTeaches is free.

Do I need to download anything?

No. It runs in a web browser on Chromebooks, Windows, Mac, iPad and phones. Python Quest runs real Python right in the browser.

Can I play without an account?

You can try the first Rover Coding lesson without signing in. Sign in with Google or with the login your teacher gave you to unlock every lesson and save your stars.

I have never coded. Where do I start?

Start with Rover Coding on the Easy level. When loops and if / else feel easy, try Python Quest.
