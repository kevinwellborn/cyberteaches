Lesson 13: If / else challenges

Time 50 minutes
Unit Conditionals
Puzzles 13.1 to 13.10

Overview

The final conditionals lesson. Students combine several if / else checks, use the right-hand rule to avoid dead ends, and learn that the order of checks matters: the most important condition (such as a tank) is checked first.

Learning objectives

Students will be able to:

  1. Use the right-hand rule with nested if / else to solve mazes with dead ends.
  2. Order conditions so the most important is checked first.
  3. Combine crystal, tank and path checks in one program.
  4. Explain how one program can solve many different maps.

Lesson procedure

Slides 4 to 5		Review if / else inside repeat until at flag. Show the right-hand rule (puzzle 13.2) and discuss ordering checks: tank, then crystal, then path (puzzle 13.9).

Think, pair, share Slides 6 to 7		Solve puzzle 13.1 (spiral) together, then pairs plan the checks for puzzle 13.9 before the reveal.

Code Slide 10		Students solve puzzles 13.1 to 13.10, ending with the final maze.
3 minClosure
Exit ticket Slide 11		Exit ticket: order the checks tank ahead → crystal here → path ahead.

Assessment

  • Formative: classwork Parts A to C, observation during coding, and the exit ticket.
  • Progress: the Teacher Dashboard shows stars per puzzle and a Lesson 13 score out of 100 (3 stars = 100, 2 stars = 90, 1 star = 80 per puzzle).
  • Success criteria: the student solves at least 7 of 10 puzzles and can explain why tank ahead is checked before path ahead.

Common misconceptions

  • Checking path ahead before tank ahead, so the rover turns away from a tank it should fire at.
  • Forgetting to move forward after turning right in the right-hand rule.
  • Building a long list of moves instead of one decision loop.

Differentiation

  • Support: provide a flowchart of the checks to follow; reuse programs from Lesson 12.
  • Extension: 3 stars on 13.7, 13.8 and 13.10; write a program that solves two different mazes.
  • Accessibility: blocks can be added by tapping or by dragging, and moved with the ▲▼ buttons.

Supports for English learners

  • Visuals: post the block pictures and vocabulary on a word wall; point to blocks while you say them.
  • Gestures: students stand and turn left or right with the rover before coding turns.
  • Partners: pair students to read programs aloud; first-language talk is welcome.
  • Sentence frames: “I check for a tank ___ because it blocks the path.” “If there is a path to the right, the rover turns ___.” “An if / else inside another if / else is a ___ if.”
  • Classwork Part E uses a word bank, pictures and fill-in sentences.

Connections

  • Careers: robot vacuums and self-driving cars use ordered decisions and sensors.
  • ELA: sequencing and priority words (first, then, otherwise).
