When it doesn't work

Debugging tips

  • Count first. Count the crystals or steps before you set the repeat number.
  • Find one copy of the pattern, build it once, then repeat it.
  • Inside or outside? Check which blocks are inside the repeat.
  • Run, watch, fix. Change one thing at a time.
Nested loops are the hardest idea so far. Encourage students to say the pattern aloud first.
