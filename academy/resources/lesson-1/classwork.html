Part A

1. The last crystal is not collected. The rover collects the first two, then drives F F to the third crystal but the program ends without a C.

2. Yes, both. F F moves right to the top-right square, R turns to face down, then F C twice collects both crystals. It stops on the bottom crystal.

Part B

3. F F F C · 4 blocks (or repeat 3 [ F ] C, 3 blocks)

4. F C F C L F C · 7 blocks. Facing down, the rover's left is the right side of the page. A common mistake is R.

Part D and Reflect

Answers vary. Look for: a correct start direction, a program a partner can follow, and a repeat used for any pattern. Reflection: use a repeat when the same steps happen again and again; it makes the program shorter and easier to read and fix.
