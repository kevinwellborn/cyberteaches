Learning goals

  • Count crystals and steps to choose the repeat number
  • Use one repeat block to collect a row of crystals
  • Use a turn before or between repeats

How would you say this pattern in a short way?

Answer

"Repeat 3 times: clap, clap, stop."

Clap a short pattern 3 times, then ask students to describe it in one sentence. Write "repeat 3 times: clap, clap, stop" on the board. This is the same idea as the repeat block.

When it doesn't work

Debugging tips

  • Count first. Count the crystals or steps before you set the repeat number.
  • Find one copy of the pattern, build it once, then repeat it.
  • Inside or outside? Check which blocks are inside the repeat.
  • Run, watch, fix. Change one thing at a time.
Ask students which tip they used most today.
