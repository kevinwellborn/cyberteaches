Part A

1. 7 squares; the box holds 4. The first loop moves 3 squares. Change makes the box 4, so the second loop moves 4 more squares: 3 + 4 = 7.

2. Lap 1: 2. Lap 2: 3. It stops on the flag. It moves 2, turns right, then moves 3 down to the flag. The program stops as soon as the rover reaches the flag, so the box still holds 3.

Part D and Reflect

Answers vary. Look for a correct start direction, a program a partner can follow, and a growing or shrinking pattern. Reflection: when the number changes while the program runs, such as a spiral or stairs that get longer each lap; a plain repeat always uses the same number.
