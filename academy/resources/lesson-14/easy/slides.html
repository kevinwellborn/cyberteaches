Variables

Lesson 14 introduces variables with one named number, steps. Plan: warm-up 5 min, slides 15 min, classwork 12 min, coding 15 min, exit ticket 3 min.
Today we will

Learning goals

  • Explain that a variable is a named box that holds a number
  • Use set steps to and change steps by
  • Use repeat steps times so every lap of a loop can be a different length
Read the goals aloud. Students check them off with the exit ticket at the end.
Warm-up · 3 minutes

The counting box

On the board: steps = 1

Each round: clap steps times, then add 1 to the box.

How many claps in round 4? What is in the box after round 4?

Answer

Round 4 = 4 claps. After round 4 the box holds 5.

Do it as a class: clap once, change the box to 2, clap twice, and so on. The box is a variable: it has a name (steps) and a number inside that changes.

When it doesn't work

Debugging tips

  • Set it first. An empty box holds 0, and repeat 0 times does nothing.
  • Set or change? Set replaces the number. Change adds to it or takes from it.
  • Inside the loop. The change block goes inside the repeat, so every lap is different.
  • Watch the box. The purple box shows steps while the rover runs. Say the number for each lap.
Most bugs are a wrong starting value or a change block outside the loop. Have students say the value of steps out loud for each lap.
