Lesson 14: Variables

Time 50 minutes
Unit Variables
Puzzles 14.1 to 14.10

Overview

Students meet their first variable: a named box called steps that holds a number. They set it, change it, and use repeat steps times so that each lap of a loop can be a different length. One short program then draws spirals, stairs and growing crystal rows that would otherwise need many blocks.

Learning objectives

Students will be able to:

  1. Explain that a variable is a named box that stores a number that can change.
  2. Use set steps to and change steps by to control a value.
  3. Use repeat steps times to make a loop run a changing number of times.
  4. Trace a program and say what is in the variable at each step.

Lesson procedure

Assessment

  • Formative: classwork Parts A to C, observation during coding, and the exit ticket.
  • Progress: the Teacher Dashboard shows stars per puzzle and a Lesson 14 score out of 100 (3 stars = 100, 2 stars = 90, 1 star = 80 per puzzle).
  • Success criteria: the student solves at least 7 of 10 puzzles and can say what is in the steps box after each lap of a loop.

Common misconceptions

  • Thinking set and change are the same (set replaces the number, change adds to it).
  • Putting change steps by outside the loop, so every lap is the same length.
  • Forgetting to set a starting value, so the box holds 0 and the loop does nothing.
  • Using the plain repeat number when the laps are different lengths.

Differentiation

  • Support: give a "box card" where students write the value of steps after each lap before they run the program.
  • Extension: 3 stars on 14.9 and 14.10; write a program that draws a spiral with change steps by +2.
  • Accessibility: blocks can be added by tapping or by dragging, and moved with the ▲▼ buttons.

Supports for English learners

  • Visuals: post the block pictures and vocabulary on a word wall; point to blocks while you say them.
  • Gestures: students stand and turn left or right with the rover before coding turns.
  • Partners: pair students to read programs aloud; first-language talk is welcome.
  • Sentence frames: “A variable is a named ___ that holds a number.” “set steps to 3 puts the number ___ in the box.” “change steps by +1 makes the number ___.”
  • Classwork Part E uses a word bank, pictures and fill-in sentences.

Connections

  • Math: variables in algebra (x) and growing patterns (1, 2, 3, …).
  • Everyday life: a scoreboard, a step counter and a bank balance are all variables.
