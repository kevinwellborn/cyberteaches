When it doesn't work

Debugging tips

  • Write the lengths. Write the list (1, 2, 3, 4 or 9, 7, 5 …) before you build.
  • Start = first length. Set steps to the first number in the list.
  • Change = the jump. The difference between two lengths is your change. Smaller each time? Use a minus.
  • Watch the box. Say the number for each lap while the rover runs.
Have students write the list of lengths on paper (or a whiteboard) before they build. Most bugs are a wrong start or a change with the wrong sign.
