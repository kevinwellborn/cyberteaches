Lesson 15: Variable practice

Time 50 minutes
Unit Variables
Puzzles 15.1 to 15.10

Overview

A practice lesson with no new blocks. Students look at a growing or shrinking pattern, find its start (the first length) and its change (the jump between lengths), and turn them into set steps to and change steps by. Puzzles count up, count down, jump by 2 or 3, and add crystals, stairs and tank alleys.

Learning objectives

Students will be able to:

  1. Find the starting value and the change in a number pattern.
  2. Use change steps by with negative numbers to count down.
  3. Combine a variable loop with collect, turns and fire.
  4. Trace the value of the variable for each lap of a loop.

Assessment

  • Formative: classwork Parts A to C, observation during coding, and the exit ticket.
  • Progress: the Teacher Dashboard shows stars per puzzle and a Lesson 15 score out of 100 (3 stars = 100, 2 stars = 90, 1 star = 80 per puzzle).
  • Success criteria: the student solves at least 8 of 10 puzzles and can name the start and the change for a list of lengths.

Common misconceptions

  • Using +1 when the lengths shrink (the change must be a minus number).
  • Setting steps to the last length instead of the first one.
  • Putting change steps by before repeat steps times, so the first lap is already the wrong length.
  • Thinking the change is always 1.

Differentiation

  • Support: give a table with two columns (lap, value of steps) to fill in before running the program.
  • Extension: 3 stars on 15.9 and 15.10; write a list of lengths for a partner and ask them for the set and change blocks.
  • Accessibility: blocks can be added by tapping or by dragging, and moved with the ▲▼ buttons.

Supports for English learners

  • Visuals: post the block pictures and vocabulary on a word wall; point to blocks while you say them.
  • Gestures: students stand and turn left or right with the rover before coding turns.
  • Partners: pair students to read programs aloud; first-language talk is welcome.
  • Sentence frames: “The lengths 1, 2, 3 grow, so I change steps by ___.” “The lengths 6, 4, 2 shrink, so I change steps by ___.” “The first length is 5, so I set steps to ___.”
  • Classwork Part E uses a word bank, pictures and fill-in sentences.

Connections

  • Math: arithmetic sequences: a start value and a common difference (1, 4, 7, 10 …).
  • Everyday life: a countdown timer, saving the same amount each week.
