New block

The if / else block

if path ahead
move forward
else
turn right

Is there a path ahead?

Yes → move forward. No → turn right.

Questions: path ahead, path left, path right, crystal here, tank ahead.

Read it aloud as a sentence. The menu on the block chooses the question.

Big idea

An if / else inside an if / else

Path ahead? → move forward.

Else: path left? → turn left. Else → turn right.

if path ahead [ F ] else [ if path left [ L ] else [ R ] ]

Three choices need two questions.

This nested decision lets the rover follow a road that turns both ways (puzzles 11.2, 11.6).

When it doesn't work

Debugging tips

  • Read it as a sentence: "If there is a path ahead, move forward, else turn right."
  • Check at every step. Put the if / else inside repeat until at flag.
  • Most important first. Check for a tank before you check the path.
  • Left or right? Paths are checked from the rover's point of view.
Encourage students to read programs aloud as English sentences.
