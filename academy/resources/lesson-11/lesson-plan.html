Lesson 11: If / else

Time 50 minutes
Unit Conditionals
Puzzles 11.1 to 11.10

Overview

Students learn the if / else block, which checks a condition (path ahead, left, right, crystal here, tank ahead) and chooses between two plans. Placed inside repeat until at flag, one short program can drive roads and mazes it has never seen. Students also nest one if / else inside another.

Learning objectives

Students will be able to:

  1. Explain how an if / else chooses between two actions.
  2. Use if / else inside a repeat-until loop to check at every step.
  3. Choose an appropriate condition (path, crystal, tank).
  4. Nest an if / else inside another to handle three choices.

Lesson procedure

Slides 4 to 6		Introduce the if / else block and its conditions. Model it inside repeat until at flag (puzzle 11.1) and show a nested if / else for a road that turns both ways.

Assessment

  • Formative: classwork Parts A to C, observation during coding, and the exit ticket.
  • Progress: the Teacher Dashboard shows stars per puzzle and a Lesson 11 score out of 100 (3 stars = 100, 2 stars = 90, 1 star = 80 per puzzle).
  • Success criteria: the student solves at least 7 of 10 puzzles and can read an if / else program aloud correctly.

Common misconceptions

  • Thinking the else part also runs when the condition is true.
  • Putting the if / else outside the loop, so it only checks once.
  • Checking path ahead before tank ahead (a tank blocks the path).

Differentiation

  • Support: provide the loop and if / else shell; students choose the condition and actions. Lesson 12 offers easier practice.
  • Extension: 3 stars on 11.5, 11.8 and 11.10; design a maze that needs a nested if / else.
  • Accessibility: blocks can be added by tapping or by dragging, and moved with the ▲▼ buttons.

Supports for English learners

  • Visuals: post the block pictures and vocabulary on a word wall; point to blocks while you say them.
  • Gestures: students stand and turn left or right with the rover before coding turns.
  • Partners: pair students to read programs aloud; first-language talk is welcome.
  • Sentence frames: “If there is a path ahead, ___ the rover moves forward.” “___, the rover turns right.” “The rover checks the ___ at every step.”
  • Classwork Part E uses a word bank, pictures and fill-in sentences.

Connections

  • ELA: conditional sentences (if … then … otherwise).
  • Science: decision trees and classification keys.
