Part D and Reflect

Answers vary. Look for a correct start direction, a program a partner can follow, and repeat until at flag that really reaches the flag. Reflection: a loop that never stops. Make sure the blocks inside move the rover closer to the flag every time.

Exit ticket

It stops by itself at the flag, so it works for any distance. You don't need to count.
