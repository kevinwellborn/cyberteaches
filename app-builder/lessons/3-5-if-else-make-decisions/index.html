If / else: make decisions

Apps make decisions all the time. Is the password right? Is the cart empty? Did the player win? An if statement checks a condition, which is a question with a true or false answer. If it is true, one block of code runs. With else, a different block runs when it is false.

Conditions compare values. Use === for "is equal to", !== for "is not equal to", and <, >, <=, >= for less than and greater than. Notice that a single = assigns a value, while === asks a question.

You can chain choices with else if, which checks another condition when the first one was false. You can also join conditions: && means "and", so both sides must be true. || means "or", so one true side is enough.

Try it: Choose a message

Only one of the three blocks runs. Change the score on the first line to see each one.

let score = 85;

if (score >= 90) {
  console.log("Amazing! You earned a gold star.");
} else if (score >= 70) {
  console.log("Nice work. You passed.");
} else {
  console.log("Keep practicing. Try again.");
}

Challenge: Add one more else if so that a score of exactly 100 shows "Perfect score!" Hint: check for 100 first.

Do this

  1. Run the code with score set to 85. Then try 95, 70, and 40. Guess the output first each time.
  2. Change the messages to ones you would want to see.
  3. Do the challenge.
  4. Write one decision your own app must make, as a sentence: "If ___, then ___, otherwise ___."

With your class: Stand up if

About 10 minutes. Working on your own? Do these steps with a friend or someone at home.

  1. One person is the caller and reads a rule to the class, such as "If you have a pet, stand up. Otherwise, put a hand on your desk."
  2. Everyone follows the rule. Notice that each person does exactly one of the two things.
  3. Take turns being the caller. Try a rule with three branches: "If..., else if..., else...".
  4. Pair up. Give your partner a score, and they say what the Try it code would print without running it.
  5. Run it to check. Then switch.

If / else: make decisions vocabulary

  • Condition: A question the code asks that is either true or false.
  • if statement: Code that runs a block only when a condition is true.
  • else: The block that runs when the condition is false.
  • else if: A second condition to check when the first one was false.
  • Comparison: Checking two values against each other, with ===, !==, <, >, <=, or >=.
  • Boolean: A value that is either true or false. Every condition produces one.
