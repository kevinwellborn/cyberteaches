App Builder topic 3.1

Choose your platform and language

A platform is where your app runs, such as a web browser or a phone. A programming language is how you write instructions for it. There are many good choices, but you only need one to start. This course teaches web apps written in HTML, CSS, and JavaScript, because they run on almost any device, cost nothing, and need nothing installed.

A web app is a website that does something, like a quiz, a planner, or a game. You can open it on a Chromebook, a laptop, or a phone, and you can share it with a link. HTML builds the parts of the page, CSS makes them look good, and JavaScript makes them do things.

Other paths work too. MIT App Inventor builds Android and iPhone apps with blocks. Python is great for games, data, and tools. If you already know one of these, you can keep using it. The ideas in this module, such as variables, if / else, loops, and lists, are the same in every language.

Try it: Your first line of code

Press Run. The computer follows each line from top to bottom. console.log shows a message in the output.

console.log("Hello, world!");
console.log("I am going to build an app.");

Challenge: Add a third line that shows the name of your app.

Do this

  1. Run the code in the Try it box below. Then change the message and run it again.
  2. Think about your app. Where will people use it: at a desk, or on a phone while walking around?
  3. Pick your platform and language. If you are not sure, choose a web app with JavaScript.
  4. Write your choice in the box below and in your build journal.

With your class: Four corners

About 10 minutes. Working on your own? Do these steps with a friend or someone at home.

  1. The corners of the room are: web app, phone app, block coding, and not sure yet. Walk to the corner that fits your app today.
  2. In your corner, agree on one good reason for your choice. One person shares it with the class.
  3. If you are in "not sure yet," ask the other corners one question each, then pick a corner.
  4. Pair up with someone from a different corner. Explain your choice in 30 seconds each.

For the Congressional App Challenge: The rules allow any platform and any programming language, including block-based languages. Your demo video must name the tools and coding languages you used.

Choose your platform and language vocabulary

  • Platform: Where an app runs, such as a web browser, a phone, or a desktop computer.
  • Programming language: A set of words and rules for writing instructions a computer can follow.
  • Web app: An app that runs in a web browser and is shared with a link.
  • JavaScript: The programming language that makes web pages interactive.
  • Code: Instructions written in a programming language.
  • Run: To have the computer carry out your code.

Quick check questions

Try each one, then open the answer. To save your progress, take this quiz in the interactive course.

1. What is the job of JavaScript in a web app?

  1. (A) It decides the colors and fonts
  2. (B) It makes the page do things when people use it
  3. (C) It stores the page on the internet
  4. (D) It draws the logo
Show answer

(B) It makes the page do things when people use it HTML builds the parts, CSS styles them, and JavaScript makes them interactive.

2. Why is a web app a good first choice?

  1. (A) It only works on expensive phones
  2. (B) It runs in a browser on almost any device and is easy to share
  3. (C) It needs no code
  4. (D) It cannot have bugs
Show answer

(B) It runs in a browser on almost any device and is easy to share Web apps run on Chromebooks, laptops, and phones, and you can share one with a link.

3. A student already knows Python well. What should they do?

  1. (A) Start over, because Python is not allowed
  2. (B) They can keep using Python, because the main ideas are the same in every language
  3. (C) Stop coding
  4. (D) Use two languages at once
Show answer

(B) They can keep using Python, because the main ideas are the same in every language Variables, if / else, loops, and lists work the same way everywhere. Use what helps you build.
